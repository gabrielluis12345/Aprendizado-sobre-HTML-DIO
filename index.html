O que aprendi sobre HTML

Neste site vou mostrar um pouco do que aprendi sobre as principais tags de HTML.

Tags de títulos

As tags de h1 até h6 são utilizadas para criar títulos e subtítulos. O h1 é o título mais importante e o h6 é o de menor destaque.

Tag p

A tag p é utilizada para criar parágrafos dentro de uma página.

Tags de formatação de texto

A tag mark deixa o texto marcado.

A tag small deixa o texto menor.

A tag i deixa o texto em itálico.

A tag u deixa o texto sublinhado.

A tag strong deixa o texto em destaque e indica importância.

A tag del mostra um texto que foi removido ou não é mais válido.

Listas

A tag ol cria uma lista ordenada:

  1. Aprender HTML
  2. Aprender CSS
  3. Aprender JavaScript

A tag ul cria uma lista sem ordem numérica:

  • HTML
  • CSS
  • JavaScript

A tag li é utilizada para representar cada item de uma lista.

Links

A tag a é utilizada para criar links para outras páginas ou sites.

Visitar o site da DIO

Subscrito e sobrescrito

A tag sub deixa o texto abaixo da linha normal. Um exemplo é a fórmula da água: H2O.

A tag sup deixa o texto acima da linha normal. Um exemplo é: 102 = 100.

Citações

A tag blockquote é utilizada para representar uma citação.

"A tecnologia está sempre evoluindo e aprender programação é acompanhar essa evolução."

Tag font

A tag font era utilizada para alterar características do texto, como cor e tamanho.

Este é um exemplo utilizando a tag font.

Atualmente essa tag é considerada antiga e normalmente utilizamos CSS para fazer esse tipo de alteração.

Tag abbr

A tag abbr é utilizada para representar uma abreviação ou sigla. Ao passar o mouse sobre ela, podemos mostrar o significado.
